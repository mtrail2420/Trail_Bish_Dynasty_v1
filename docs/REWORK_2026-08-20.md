# Rework pass — 2026-08-20

Fixes applied after auditing the V1 production build (chap's review + direct
code verification). All four confirmed issues from that review, fixed and
tested against the live backend workbook.

## 1. `verify_scores.py` — ring detector false positives (FIXED)

**Bug:** plain substring matching. `"ring"` matched inside `"during"`.
`_RING_WORDS = ("champion", "super bowl", "sb ", "ring")` checked with
`in`, not word boundaries. Also flagged mere Super Bowl *appearances*
("Super Bowl starter/participant/appearance") as if they were win claims.

**Fix:** switched to word-boundary regex patterns (`\bchampion\b`,
`\brings?\b`, `\bwon\b.*\bsuper bowl`) and narrowed the semantic check to
actual win claims, not participation.

**Verified:** ran the script against the real backend before and after.
Before: 10 FAILs (Matt Ryan, Cam Newton, Blake Bortles, Clive Walford,
Jared Goff, Scooby Wright III, Vadal Alexander, Artie Burns, Mike
McGlinchey, Joe Burrow — none of whom actually won a Super Bowl). After:
0 FAILs, PASS.

## 2. `core/components.py` — Franchise/Legend tier inconsistency (FIXED)

**Bug:** the rivalry banner's mini-stat counted
`CAREER_TIER == 'Franchise'` literally instead of using the centralized
`FRANCHISE_TIERS` frozenset (`{"Legend", "Franchise"}`) already defined
in `core/stats.py` and used elsewhere. A future Legend-tier player would
silently disappear from this specific count.

**Fix:** now uses `df['CAREER_TIER'].isin(FRANCHISE_TIERS)`, relabeled
"Franchise" → "Elite" since it counts both tiers.

## 3. `pages/Dashboard.py` — "Best Value Picks" mislabeled (FIXED)

**Bug:** section claimed to show "Round 3+ players who outperformed
their draft slot," but the underlying query is just
`df[ROUND >= 3].sort_values("OVERALL SCORE").head(3)` — top scorers in
round 3+, with no draft-slot expectation computed anywhere.

**Fix:** renamed to "BEST LATE-ROUND PICKS" / "Highest-scoring players
selected Round 3+" — accurately describes what the code does.
